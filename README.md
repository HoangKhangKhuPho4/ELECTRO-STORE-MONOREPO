### 🧩 Danh Sách 12 Microservices & Cổng Dịch Vụ

| TT | Tên Service | Port | Công Nghệ / Vai Trò |
| :---: | :--- | :---: | :--- |
| **1** | **`discovery-server`** | `8761` | Spring Cloud Netflix Eureka (Service Registry) |
| **2** | **`config-server`** | `8888` | Spring Cloud Config Server |
| **3** | **`api-gateway`** | `8080` | Spring Cloud Gateway (Routing & JWT Security) |
| **4** | **`auth-service`** | `8081` | Spring Boot, JWT, Redis Cache |
| **5** | **`catalog-service`** | `8082` | Spring Boot, MySQL (Danh mục & Tồn kho) |
| **6** | **`user-service`** | `8083` | Spring Boot, MySQL (Hồ sơ người dùng & Wishlist) |
| **7** | **`cart-service`** | `8084` | Spring Boot, MySQL (Quản lý giỏ hàng) |
| **8** | **`order-service`** | `8086` | Spring Boot, MySQL (Đơn hàng & Bảo hành) |
| **9** | **`review-service`** | `8087` | Spring Boot, MySQL (Đánh giá sản phẩm) |
| **10** | **`statistics-service`** | `8088` | Spring Boot, Redis Cache (Thống kê doanh số) |
| **11** | **`chatbot-service`** | `8092` | Spring Boot, Pinecone Vector DB (RAG AI) |
| **12** | **`reco-service`** | `5003` | Python FastAPI (Gợi ý SVD + KNN) |
| **--** | **`frontend`** | `5173` | React 19, Vite, MUI v7 (Giao diện mua sắm) |

### 🚀 Khởi Chạy Nhanh (1-Click PowerShell)
```powershell
# Khởi động toàn bộ 12 Services + Hạ tầng Docker (MySQL, Redis, Zipkin):
.\START.ps1

# Kiểm tra trạng thái sức khỏe tất cả services:
.\check-all-services.ps1

# Dừng toàn bộ hệ thống:
.\STOP.ps1
```
